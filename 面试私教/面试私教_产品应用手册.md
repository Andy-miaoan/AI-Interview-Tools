## 2. 核心理念：覆盖求职全周期

面试私教不只帮你准备一个面试，而是覆盖从"改简历"到"试用期过关"的完整求职链路：

```
你的求职旅程
    ├── 📝 简历优化 → 痛点诊断 + 逐段改写 + JD差距分析
    ├── 📄 生成简历 → 零经验也能出A4满版简历
    ├── 🎤 模拟面试 → 实时对话练习 + 5维能力雷达追踪
    ├── 💰 谈薪指导 → 三轮谈判话术 + 非现金筹码策略
    ├── ⚖️ Offer决策 → 多Offer量化对比 + 加权评分
    └── 🛡️ 试用期护航 → 30/60/90天计划 + 风险诊断 + 自保策略
```

**核心理念：你负责做决定，AI负责给你所有决策依据。**

## 5. 模块详解

### 5.1 简历优化 — 你的简历AI诊断师

**用途**：上传或粘贴简历 → AI逐项诊断 → 输出可直接用的改写版本 + JD匹配度分析。

**支持的文件格式**：
- PDF（含文字层）
- Word（.docx / .doc）
- 纯文本（.txt / .md）
- 支持拖拽上传和点击上传

**输入字段**：

| 字段 | 必填 | 说明 |
|------|------|------|
| 目标岗位 | 选填 | AI会针对该岗位优化措辞 |
| 目标岗位JD | 选填 | 粘贴JD后可激活「JD差距分析」 |
| 简历内容 | 必填 | 上传文件后自动填入，或手动粘贴 |

**AI分析5步诊断法**：

1. **整体印象**：排版、长度、第一眼专业感
2. **结构问题**：信息架构是否清晰、逻辑是否顺畅
3. **逐段改写**：每段有具体改写建议，附带改写范例
4. **格式检查**：日期一致性、数字准确性、术语规范
5. **匹配度分析**（需填JD）：逐条对照JD要求 vs 简历内容

**特色功能**：

- **📊 简历竞争力评分**（自动）：
  - 从6个维度打分：工作经验、项目深度、技能匹配、学历背景、数据量化、语言表达
  - 综合评分0-100分，分高/中/低三档
  - 绿色=强项，黄色=可改进，红色=短板

- **🔍 JD差距分析**（需同时填写JD）：
  - 逐条对比JD要求与简历内容的匹配情况
  - 每条标注「✅ 满足」「⚠️ 部分满足」「❌ 缺失」
  - 输出"你需要补充的关键词"和"应该弱化的内容"

- **🔄 改写前后对比**（AI结果区域）：
  - 左侧：原始简历（标红问题段落）
  - 右侧：优化建议（逐条改写范例）

**生成后的操作**：

| 按钮 | 作用 |
|------|------|
| ⏭ 生成完整简历 | 跳转到「生成简历」模块，基于优化内容AI生成完整简历 |
| ⏭ 模拟面试练习 | 跳转到「模拟面试」，AI开始针对性提问 |
| 📋 一键复制 | 复制结果到剪贴板，可跳转外部AI |
| 🤖 直接分析 | 如果配置了API Key，直接在页面内调用AI（无需跳转） |

### 5.2 生成简历 — 零经验也能出好简历

**用途**：根据你的基本信息，AI从零生成一份结构完整、排版标准的A4简历。

**适合人群**：
- 应届生：没有工作经验不会写
- 转行者：不知道怎么写新行业的简历
- 简历被HR批"太简单"的人

**输入字段**：

| 字段 | 说明 |
|------|------|
| 目标岗位 * | AI以此为核心生成整份简历 |
| 工作/实习经历 | 公司·岗位·时间段·做了什么，逗号分隔多条 |
| 项目经验 | 项目名·角色·成果，逗号分隔 |
| 学历 | 学校·专业·学位 |
| 技能证书 | 硬技能、语言、证书等 |
| 自我评价方向 | 关键词即可，如"执行力强、善于沟通、结果导向" |

**模板风格（3种可选）**：
- 🏢 经典专业 — 适合传统行业（金融、制造、国企）
- 🚀 现代极简 — 适合互联网/科技公司
- 🎨 创意个性 — 适合设计/市场/产品

**输出结构**（约800-1200字，A4满版）：
1. 个人信息区（姓名·意向岗位·城市·邮箱·电话）
2. 个人总结（3-4句，针对性提炼）
3. 工作经历（STAR法则表述）
4. 项目经验（成果量化）
5. 教育背景
6. 技能&证书

**生成后的下一步**：
- ⏭ 模拟面试练习（AI基于新简历出题）
- 可复制到Word/飞书文档二次排版

### 5.3 模拟面试 — 真刀真枪练面试

**用途**：AI面试官与你进行实时对话，模拟真实面试场景。记录你的表现并给出5维能力评分。

**两种模式**：

| 模式 | 适合 | 特点 |
|------|------|------|
| 💬 对话模式 | 首次练习 | AI提问 → 你打字回答 → AI追问/给反馈 |
| 📋 指令模式 | 生成完整题库 | 输出初面+复试+终面完整题库 |

**对话模式输入字段**：

| 字段 | 说明 |
|------|------|
| 目标岗位 * | 面试的岗位 |
| 面试级别 | 初级/中级/高级/管理岗 |
| 你担心的问题 | 告诉AI你怕被问到什么，AI会针对性帮你练 |

**对话模式流程**：

1. 点击「▶ 开始面试」→ AI面试官发出第一个问题
2. 你在底部输入框键入回答 → 按回车发送
3. AI给出两种反馈（可切换）：
   - 📝 **继续提问**：基于你的回答追问下一题
   - 💡 **即时辅导**：点评你的回答，告诉你怎么答更好（黄色气泡）
4. 随时可以点击「🏁 结束面试」
5. 结束后面试记录自动保存到本地

**能力追踪（5维雷达图）**：

每次对话练习后，AI从5个维度评估你的表现：

- 🗣️ 沟通表达：清晰度、条理性、语言组织
- 🎯 专业能力：知识深度、项目理解
- 🧠 逻辑思维：结构化思考、因果关系
- 🔀 临场应变：追问应对、压力处理
- 🤝 文化匹配：价值观、协作风格

每次练习后可以看到：
- 5维雷达图（含本次得分 vs 上次得分对比）
- 趋势箭头：📈 进步还是 📉 退步
- 各维度具体分数

**指令模式输出**：
- 初面题库：基础能力 + 岗位认知
- 复试题库：专业深度 + 情景模拟
- 终面题库：文化匹配 + 职业规划 + 压力题
- 每道题附带回答要点提示

**面试风格切换**：
- 👔 大厂模式：重底层能力、系统设计、行为面试
- 🚀 创业模式：重实战经验、速度、ownership
- ⚖️ 混合模式：兼顾以上两种

### 5.4 谈薪指导 — 多说一句话多拿30%

**用途**：根据你的情况和市场行情，AI生成三轮谈判话术和最优惠方案分析。

**输入字段**：

| 字段 | 必填 | 说明 |
|------|------|------|
| 目标岗位 | * | 岗位名称 |
| 所在城市 | * | 影响薪资基准 |
| 级别 | * | 初级/中级/高级/管理岗 |
| 当前薪资（月薪） | 选填 | 谈判的重要筹码 |
| 期望薪资（月薪） | * | 你的目标 |
| Offer已给薪资 | 选填 | 有offer时更精准 |
| 特殊情况 | 选填 | 如：有其他offer、急需入职、有期权、异地搬家等 |

**输出内容**：
1. 谈薪策略一句话
2. 市场价位分析（基于岗位+城市+级别）
3. 你的筹码评估（哪些点可以拿出来谈）
4. 三轮谈判话术：
   - 第一轮：首轮报价/还价怎么说
   - 第二轮：对方压价时的应对
   - 第三轮：最终博弈 + 非现金筹码（公积金、年假、期权、培训等）
5. 对方可能的还价 + 你的应对策略
6. 签约前要确认的问题清单

**⚠️ 重要提醒**：
- AI给出的是策略建议，具体数字需要你自己判断
- "还有其他offer"是最强的谈判筹码，慎用但有效
- 非现金福利有时比月薪多2K更有价值

### 5.5 试用期护航 — 安全度过前90天

**用途**：入职前/入职中制定试用期生存计划，遇到问题时AI帮你分析风险并给出自保策略。

**两种模式**：

| 模式 | 用途 | 输入重点 |
|------|------|----------|
| 📅 试用期计划 | 入职前制定 | 岗位、级别、试用期时长、团队规模、主管风格 |
| ⚠️ 风险诊断 | 入职后遇到问题 | 岗位、已入职时长、观察到的异常表现 |

**输出内容**：

**试用期计划（📅模式）**：
- 30天里程碑：该学什么、该认识谁、该出什么成果
- 60天里程碑：该做什么、该证明什么
- 90天里程碑：转正答辩准备清单
- 每周自检问题清单

**风险诊断（⚠️模式）**：
- 问题严重程度评估（🟢低 / 🟡中 / 🟠高 / 🔴危急）
- 具体问题分析和可能原因
- 你的自保策略（该找谁、该记录什么、该做的准备）
- 是否需要主动找下家（客观判断，不贩卖焦虑）

**⚠️ 重要提醒**：
- AI的建议是客观分析，不是法律建议
- 遇到劳动纠纷请咨询专业律师
- 试用期被辞退也要依法补偿

### 5.6 Offer决策 — 多Offer对比不再纠结

**用途**：输入多个Offer → 设置各维度权重 → 系统量化对比 → AI给出推荐理由。

**添加Offer**：
点击「➕ 添加Offer」→ 输入以下信息：

| 字段 | 说明 |
|------|------|
| 公司名称 * | 如：字节跳动 |
| 月薪 | 如：25,000 |
| 年终 | 如：15薪 |
| 公积金比例 | 如：12% |
| 股票/期权 | 如：价值约XX万/4年 |
| 工作时长 | 如：10-7-5（早10晚7上5天） |
| 通勤时间 | 如：地铁40分钟 |
| 成长空间 | 如：高/中/低 |
| 团队氛围 | 如：好/中/差 |
| 备注 | 任何你认为重要的信息（行业前景、直属领导印象等） |

**权重设置**：
添加2个以上Offer后，出现权重滑块（0-10分可调）：

| 维度 | 默认权重 | 说明 |
|------|---------|------|
| 💰 薪资 | 5 | 月薪+年终+公积金 |
| 📈 成长 | 5 | 晋升空间、学习机会、行业前景 |
| ⏰ 生活 | 5 | 通勤+工作时长+加班文化 |
| 👥 氛围 | 5 | 团队氛围、直属领导、公司文化 |

权重越高，该维度对最终结果影响越大。按你个人价值观调整。

**对比结果**：
- 对比表格：每个Offer在各维度的量化得分
- 🏆 综合冠军：显示最高分Offer及总得分
- 逐条推荐理由
- 最终决策建议 + 一句话核心理由

**决策建议格式**：

## 11. 常见问题

### Q1: 数据安全吗？

**A**: 非常安全。所有数据（个人简要、历史记录、API Key等）全部存储在**你本机浏览器**的 localStorage 中，不上传任何服务器。唯一用到外部API的是：
- 激活码验证（jsonblob.com）
- AI调用（你配置的API平台）

### Q2: 激活码过期了怎么办？

**A**: 联系客服微信 **miaoan1913** 续费。页面顶部会在到期前7天出现提示条。

### Q3: 可以多设备使用吗？

**A**: 可以。用「📦 备份」导出 → 在另一台设备上激活登录 → 「📂 恢复」导入，数据就同步过去了。

### Q4: 模拟面试和真AI面试官有什么不同？

**A**: 模拟面试是基于你的输入生成面试题库或进行对话练习。如果你需要"AI自动提问+你回答+AI分析你的临场表现"的更深入服务，可以咨询客服了解「职业陪跑」产品线的更多功能。

### Q5: API Key必须配置吗？

**A**: 不必须。不配置API Key也可以正常使用产品的所有功能。区别在于：
- 无API Key：生成指令 → 点击「📋 一键复制」→ 粘贴到外部AI（DeepSeek/豆包等）
- 有API Key：点击「🤖 直接分析」→ 页面内出结果

两种方式得到的结果质量相同，只是操作步骤不同。

### Q6: Offer决策的权重怎么设？

**A**: 没有标准答案，按你当前阶段的需求来：

| 如果你 | 建议调整 |
|--------|---------|
| 刚毕业2年内 | 成长权重拉满（7-8分） |
| 养家还房贷 | 薪资权重拉满（7-8分） |
| 住得远/带娃 | 生活权重多给点 |
| 内向敏感 | 氛围权重很重要 |
| 不确定 | 全部5分，让AI帮你发现偏好 |

### Q7: 简历优化的JD差距分析准吗？

**A**: JD差距分析逐条对照JD要求与简历内容，帮你发现：
- 你的简历漏写了什么（明明会但没写进去）
- 你应该补充学什么（JD要求但你确实不会的）
- 你应该弱化什么（跟目标岗位无关的内容）

它比你自己盯着JD看半小时要系统得多。

### Q8: 试用期风险诊断说我"建议找下家"，我真的要辞职吗？

**A**: AI给出的判断是根据你输入的信息做的客观分析。如果AI判断风险很高（🔴级别），建议你：
1. 冷静2天再做决定
2. 跟信任的朋友/前辈聊一聊实际情况
3. 不要裸辞，边看机会边观察
4. AI不是预言家，最终是你自己的选择
